<h3>About Me</h3>

Hello! I'm Thierry Barreto, a developer passionate about programming, technology, and software development.

I'm currently pursuing a degree in Systems Analysis and Development (ADS) at UniCesumar, where I'm building a strong foundation in software engineering, programming logic, and application development.

My main focus is on FrontEnd Development, working with technologies such as HTML, CSS, JavaScript, TypeScript, and React. I'm also expanding my knowledge of BackEnd Development, exploring Node.js and other technologies to better understand how full-stack applications are built.

I enjoy turning ideas into functional projects, solving problems through code, and continuously challenging myself to learn new things. I believe that hands-on experience, curiosity, and consistency are essential to becoming a better developer.

I'm always looking to improve my skills, collaborate on projects, and grow professionally in the technology industry.
